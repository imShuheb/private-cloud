# Community Release & Versioning

This document tracks the evolution of **Private Storage** into a definitive community utility.

| Version | Phase | Theme | Status | Key Feature |
| :--- | :--- | :--- | :--- | :--- |
| **v1.1.x** | **Live** | Multi-Connection | ✅ Stable | Secure Multi-S3 Explorer |
| **v1.2.0** | **P1** | Community Foundation | 🔨 Planned | Postgres + TimescaleDB Migration |
| **v1.5.0** | **P2** | Insight Engine | 📅 Upcoming | Inventory Ingestion & Usage Reports |
| **v1.8.0** | **P3** | Sovereignty | 📅 Future | Egress Radar & Permissions Analyzer |
| **2.0.0** | **P4** | Autopilot | 🎯 Community Launch | One-Click Cleanup & Automation |

## 🚀 The v2.0 Community Milestone
The project will formally evolve from **Private Storage** to **Storage Insight** at the v2.0.0 milestone.

### Key Milestones:
1. **The DB Pivot (v1.2)**: This is the most critical technical step. We ensure the stack can handle large-scale datasets for all community members.
2. **The "Value" Release (v1.5)**: The first time the user sees a "usage breakdown" of their storage. This proves the tool as an essential utility.
3. **The Sovereignty Release (v1.8)**: Moving from a tool for "Files" to a tool for "Cloud Management."

### Open Source Stewardship
During the v1.2.x cycle, we will continue to bug-fix the existing explorer while the core architecture is being rebuilt in the background.
